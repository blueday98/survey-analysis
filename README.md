# 러닝 자세 분석 서비스 사용자 설문 EDA

러닝 자세 분석 서비스의 사용자 요구, 사용 의향, 촬영 장벽 및 지불 의향을 파악하기 위해 진행한 설문조사 분석 프로젝트입니다.

## 프로젝트 목적

다음 질문에 답하는 것을 목표로 합니다.

* 러너가 자신의 자세를 확인하거나 개선하면서 겪는 어려움은 무엇인가?
* 러닝 자세 분석 서비스에 대한 사용 의향은 어느 정도인가?
* 영상 촬영과 업로드 과정에서 발생하는 주요 장벽은 무엇인가?
* 사용자가 분석 결과를 신뢰하기 위해 필요한 정보는 무엇인가?
* MVP에서 우선 구현해야 할 기능은 무엇인가?
* 서비스 이용과 지불 가능성이 높은 초기 고객군은 누구인가?

## 데이터 개요

* 설문 응답자: 21명
* 전체 문항: 28개
* 분석 문항: 26개
* 데이터 형태: 단일선택, 복수선택, 5점 척도 및 자유서술형 문항
* 조사 방식: 편의표본 기반 자기보고 설문

타임스탬프와 후속 인터뷰 참여자의 이름은 분석에서 제외했습니다.

## 개인정보 보호

원본 설문에는 타임스탬프와 후속 인터뷰 신청자의 이름이 포함되어 있어 공개하지 않습니다.

* 원본 데이터는 `data/raw/`에 로컬로만 보관합니다.
* `data/raw/`는 `.gitignore`에 등록되어 있습니다.
* 분석 시 타임스탬프와 이름 컬럼을 즉시 제거합니다.
* 자유서술형 응답은 개인을 추정할 수 있는 내용이 없는지 검토한 후 사용합니다.
* GitHub에는 분석 코드와 집계된 결과만 공개합니다.

## 초기 분석 방향

현재 다음 영역을 중심으로 탐색적 데이터 분석을 진행하고 있습니다.

1. 응답자 및 러너 구성
2. 러닝 자세 개선 경험
3. 기존 자세 확인 방법의 한계
4. 서비스 사용 의향
5. 영상 촬영 및 업로드 장벽
6. 분석 결과에 필요한 기능과 신뢰 조건
7. 피드백 적용 및 재분석 의향
8. 조건부 지불 의향
9. 초기 고객 후보군 탐색

## 초기 요약

초기 응답 요약에서는 러닝 자세 분석 서비스에 대한 관심과 필요성이 확인됐지만, 촬영 과정과 유료 결제 의향이 주요 장벽으로 나타났습니다.

분석 결과의 판단 이유와 기준을 명확하게 설명하는 기능이 중요하게 평가됐으며, 촬영 편의성과 개인정보 보호 조건도 서비스 도입에 영향을 미치는 요소로 확인됐습니다.

> 현재 수치는 소규모 편의표본을 기반으로 한 탐색적 결과입니다. 최종 분석에서는 각 지표의 분자, 분모 및 계산 기준을 원자료에서 다시 확인합니다.

## 분석 원칙

* 응답 인원과 비율은 원본 CSV에서 계산합니다.
* 긍정 응답과 초기 고객 후보군의 분류 기준을 코드에 명시합니다.
* 복수응답 문항은 응답을 분리하여 선택 빈도를 계산합니다.
* 결측치는 설문 분기로 인한 구조적 결측과 실제 무응답을 구분합니다.
* 소표본이므로 p-value만으로 결론을 내리지 않습니다.
* 교차표, 효과크기와 실제 응답 분포를 함께 해석합니다.
* 분석 결과를 전체 러너 모집단으로 일반화하지 않습니다.

## 실행 방법

### 1. 저장소 내려받기

```bash
git clone <repository-url>
cd survey-analysis
```

### 2. 가상환경 생성 및 활성화

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. 패키지 설치

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

### 4. Jupyter 실행

```bash
jupyter lab
```

## 분석의 한계

* 전체 응답자가 21명인 소규모 표본입니다.
* 무작위 표집이 아닌 편의표본입니다.
* 실제 서비스 사용 행동이 아닌 자기보고 응답입니다.
* 실제 가격을 제시한 결제 실험이 아닙니다.
* 일부 문항은 설문 분기에 따라 구조적으로 결측될 수 있습니다.
* 분석 결과는 가설의 확정보다 MVP 방향성을 탐색하는 목적으로 해석해야 합니다.

## 후속 검증 계획

초기 고객 후보에게 실제 프로토타입을 제공하고 다음 행동 지표를 측정할 예정입니다.

* 촬영 시작률 및 완료율
* 영상 업로드 완료율
* 분석 결과의 이해도와 신뢰도
* 피드백 적용률
* 재촬영 및 재분석률
* 가격을 제시했을 때의 결제 또는 예약 행동

## 핵심 방향

첫 번째 MVP는 다음 흐름에 집중합니다.

```text
간단한 촬영 안내 → 러닝 자세 분석 → 판단 근거가 포함된 피드백
```

전후 영상 비교와 장기 변화 추적 기능은 실제 프로토타입 검증 결과에 따라 후속 기능으로 검토합니다.
